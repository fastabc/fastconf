# FastConf 可复现性能比较（2026-10-25）

本次使用当前 FastConf 工作树重新测量，覆盖启动、重载、热读、文件、环境变量和诊断成本。
下表比较固定适配方式与输入，不能推导所有应用、格式或数据结构的性能排序。
最终发布审查的代码修正在测量之后，不包含在本报告的性能结果中。

## 测量范围

- Apple M5 Pro，Darwin 27.0.0 / arm64，Go 1.26.10，GOMAXPROCS=4，GOGC=100。
- FastConf 模块版本为 `v1.2.0`，独立比较模块通过 `replace => ../..` 使用当前本地源码；来源为 `03e6a957c5ad8ba20f11dc6f649ca77129aa7fa4` 加本次代码/测试精简与优化工作树，不是公共代理上已发布版本的测量。
- 测量时完整源码校验和见 `source-sha256.txt`，工作树差异摘要见 `environment.txt`；报告及文档在测量后更新，运行时源码未再改动。
- Viper 1.21.0、Koanf 2.3.0、Cleanenv 1.5.0、Envconfig 1.4.0；依赖由独立 go.mod/go.sum 固定，未在本轮升级竞品版本。
- 68 组 benchmark，每组 10 次、benchtime=1s，共 680 行样本。下表为十次中位数；benchstat 区间与离散程度保存在 summary.txt。
- 27 个独立进程各记录 100 次重载，共 2700 条延迟样本；分别记录进程峰值 RSS。
- 比较适配器先通过独立 race 检查。计时期间未并行运行本次任务的构建、race 或其他检查；操作系统和其他应用仍可能产生调度噪声。

此前报告使用不同源码快照，不能把两次比较报告的差异直接归因于某个优化。
本轮核心优化使用同一夹具的三次针对性前后测量，另见[性能说明](../../docs/design/perf.md)。
亚纳秒热读是紧循环吞吐量，不能当作业务请求延迟保证；部署决策应在目标环境复测。

这里没有文件输入指纹的快速跳过。单位：毫秒/次。

## FastConf 诊断与历史成本

| 输入 | 操作 | ms/op | 分配 MiB/op | allocs/op |
| --- | ---: | ---: | ---: | ---: |
| 4KiB | 已缓存视图的 Map 复制 | 0.0032 | 0.0111 | 68 |
| 4KiB | 有效重载 + history=8 + 冷 Map | 0.1458 | 0.1569 | 1784 |
| 64KiB | 已缓存视图的 Map 复制 | 0.0510 | 0.1734 | 1028 |
| 64KiB | 有效重载 + history=8 + 冷 Map | 2.0775 | 2.3161 | 25865 |
| 1024KiB | 已缓存视图的 Map 复制 | 0.8117 | 2.7503 | 16388 |
| 1024KiB | 有效重载 + history=8 + 冷 Map | 30.3126 | 38.2013 | 416028 |

Map 返回调用方可修改的副本，已缓存视图仍需要复制。本轮的不可变类型/路径脱敏计划
由 Manager 构造并共享；此比较夹具没有 fc secret 字段，带秘密类型的针对性测量见性能说明。
冷路径和历史测试包含完整重载，不应把其全部成本归于历史环。无同等接口的竞品未进入此项。

文件版本缓存只影响文件输入，不能从此 Provider 比较推断它的收益。当前策略只保留每个
路径/codec 的最新成功版本；恢复旧文件内容要重新解码，相关内存收益和交替版本代价均在性能说明中记录。

## 复现与原始证据

本次按顺序执行，避免 correctness 与计时并发：

```sh
cd benchmarks/compare
GOWORK=off GOMAXPROCS=4 go test -mod=readonly -race -count=1 ./...
GOMAXPROCS=4 GOGC=100 COUNT=10 BENCHTIME=1s SAMPLES=100 bash run.sh results/2026-10-25
```

[适配器、范围与官方 API 来源](README.md)说明比较契约。runner 生成 raw.txt、
summary.txt、environment.txt、modules.txt、correctness.txt、source-sha256.txt，
以及 27 组延迟 JSON 与 RSS 文件。

本次产物在本地 `results/2026-10-25/`，旧日期目录保留。整个 results/ 被 Git 忽略；
克隆仓库后需要重新执行命令生成原始证据，报告表格由本次实际样本计算。

未测多层目录、真实远程服务、Kubernetes 投射卷、跨机器/平台性能，也没有复制所有
生产校验、订阅和密钥处理成本。实际采用仍应结合输入规模、变更频率及发布流程复测。
